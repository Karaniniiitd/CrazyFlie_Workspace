Workspace
---------
~/cf_ws

============================================================
TERMINAL 1 : START CRAZYFLIE SERVER
============================================================

Step 1

cd ~/cf_ws

Step 2

source /opt/ros/humble/setup.bash

Step 3

source install/setup.bash

Step 4

ros2 launch crazyflie launch.py

Keep this terminal OPEN.

Expected:

✓ crazyflie_server started
✓ teleop started
✓ joy_node started
✓ Logging to /pose
✓ Logging to /status

DO NOT CLOSE THIS TERMINAL.

============================================================
TERMINAL 2 : VERIFY CONNECTION
============================================================

Open a NEW terminal.

Step 1

cd ~/cf_ws

Step 2

source /opt/ros/humble/setup.bash

Step 3

source install/setup.bash

------------------------------------------------------------

Check ROS Nodes

ros2 node list

Expected Output

/crazyflie_server

------------------------------------------------------------

Check Services

ros2 service list | grep cf231

Expected Output

/...
/cf231/takeoff
/cf231/land
/cf231/go_to
/cf231/emergency

------------------------------------------------------------

Check Drone Status

ros2 topic echo /cf231/status --once

Expected

Battery Voltage
RSSI
Link Status

============================================================
TERMINAL 2 : TAKEOFF
============================================================

ros2 service call \
/cf231/takeoff \
crazyflie_interfaces/srv/Takeoff \
"{group_mask: 0,
height: 0.2,
duration: {sec: 2, nanosec: 0}}"

Drone should take off.

============================================================
TERMINAL 2 : LAND
============================================================

ros2 service call \
/cf231/land \
crazyflie_interfaces/srv/Land \
"{group_mask: 0,
height: 0.0,
duration: {sec: 2, nanosec: 0}}"

Drone should land safely.

============================================================
TERMINAL 2 : EMERGENCY STOP
============================================================

ros2 service call \
/cf231/emergency \
std_srvs/srv/Empty

Use ONLY if required.
